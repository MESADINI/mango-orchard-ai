# Dataset card: External test set (cross-dataset generalisation)

Tables marked AUTO are generated by `ml/datasets/make_cards.py` from `results/data/external_testset.json`.

## Purpose

This set is **never used for training, model selection or threshold tuning.** It measures how a model trained on
MangoLeafBD performs on mango leaves photographed in other orchards, in another year, with other devices.

## Source

- **Citation:** Rahman, M.S., Hasan, R., Mojumdar, M.U. (2024). *Mango Leaf Disease Dataset.* Mendeley Data, V1,
  doi:10.17632/7ghdbftp54.1.
- **License:** CC BY 4.0.
- **Collection (per the record):** Kashinathpur (Pabna) and Changao (Savar), Bangladesh, Oct–Nov 2024.
- **Download:** a single archive (1,415,346,191 bytes, SHA-256 verified in `build_external_testset.py`). It contains two
  inner archives: `process data.zip` (original images) and `Augmented Image.zip`. **Only the originals are used**,
  because augmented copies would inflate the count and are not independent.

## Provenance finding: the source is only partly independent

Most images in `process data.zip` have **exactly MangoLeafBD's pixel sizes** (240×320, 320×240, 240×240, …).
On inspection they are **MangoLeafBD leaves with the background replaced by black**. The leakage guard
independently confirms 581 of these 972 images as geometric matches to specific MangoLeafBD images (`excluded.csv`
lists the matched SHA-256 values). Every Healthy image is in this group. Only the images at native camera resolution
(960×1280, 3000×4000, 1200×1600, 1000×1000, …) look like new photographs, and none of those 381 matches
MangoLeafBD.

## Processing (`ml/datasets/build_external_testset.py`)

1. Keep the non-augmented images of the five model classes (`Sooty Mould` → `Sooty Mold`). Cutting Weevil, Gall
   Midge and Die Back are skipped, matching the training set.
2. Remove exact duplicates within the set.
3. **Format rule:** exclude every image whose size is one of MangoLeafBD's sizes (probable derivative).
4. **Leakage guard:** compare each remaining image with every MangoLeafBD image using the same criteria as the
   training de-duplication (SHA-256, dihedral pHash = 0, or a top-40 DINOv2 neighbour with ≥ 12 one-to-one SIFT/RANSAC
   inliers). Matches are excluded.
5. Output: `ml/datasets/processed/external/<Class>/` with `manifest.csv` (kept images, each with its nearest-match
   statistics) and `excluded.csv` (each excluded image with its reason and best-matching MangoLeafBD SHA-256).

## Known limitations

- **There is no Healthy class** (all Healthy images are MangoLeafBD derivatives), so the set cannot measure false
  alarms on healthy leaves. Report per-class recall and the 4-class confusion matrix, not overall accuracy.
- The class balance is very uneven (see the table). Bacterial Canker dominates.
- Still Bangladesh and still mostly single leaves, so this measures a *dataset shift*, not true field
  conditions in Tamil Nadu. For that, use `ml/datasets/field/`.
- Labels are the dataset authors'; they were not re-verified by a pathologist.

## Reproduce

```
python ml/datasets/build_disease_dataset.py      # needs its feature cache for the leakage guard
python ml/datasets/build_external_testset.py
```
