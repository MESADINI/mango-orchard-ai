# Datasets

Every dataset is rebuilt from scratch by scripts in this folder (`python tasks.py data` runs them all). Each step
checks SHA-256 checksums and writes its evidence to `results/data/`. Dataset cards with all counts are in
`docs/datasets/`.

| Script | Output | Card |
|---|---|---|
| `download_mangoleafbd.py` | `raw/mangoleafbd/` (4,000 images, verified against the authors' Mendeley checksums) | `docs/datasets/mangoleafbd.md` |
| `build_disease_dataset.py` | `processed/disease/{train,val,test}/<Class>/`, `split.csv` (near-duplicate groups, 70/15/15, 5 CV folds) | `docs/datasets/mangoleafbd.md` |
| `build_external_testset.py` | `processed/external/<Class>/`, `manifest.csv` (independent 2024 dataset; never trained on) | `docs/datasets/external.md` |
| `build_pest_dataset.py` | `processed/pest/` + `data.yaml` (needs `ROBOFLOW_API_KEY`) | `docs/datasets/pest.md` |
| `data_stats.py` | `results/data_stats.json` | |
| `make_cards.py` | refreshes the AUTO tables in `docs/datasets/*.md` | |

Helpers: `dedup.py` (dihedral pHash + DINOv2 near-duplicate grouping) and `fetch.py` (resumable parallel download).
Your own orchard photos go in `field/` (see `field/README.md`).

## Classes

- **Disease (5):** Anthracnose, Bacterial Canker, Powdery Mildew, Sooty Mold, Healthy. *Leaf Spot* was dropped:
  MangoLeafBD has no such class and no licensed mango Leaf Spot image set was found.
- **Pest (3, flagged proxy data):** Fruit Fly, Mealy Bug, Scale Insect. The public sources show trap, grape and coffee
  images, not mango (`pest_source_review.json`).
- **Gated (Rule 3, never trained):** Mango Hopper, Stem Borer, until ≥ 100 verified boxes exist
  (`pest/MANUAL_ANNOTATION_GUIDE.md`).

`raw/` and `processed/` are git-ignored and are regenerated by the scripts.
